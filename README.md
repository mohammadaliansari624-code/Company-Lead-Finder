# Company Lead Finder 🚀

This is a Python-based automation script that takes a company's name as input and fetches its comprehensive details, including the website domain, LinkedIn profile, location, and employee count.

It combines two powerful APIs to achieve this:
1. **Clearbit Autocomplete API:** To find the exact domain name from the company's text name.
2. **Apollo.io API:** To enrich the domain with detailed organizational data.

## Features ✨
* Automatically finds the correct website domain for a given company.
* Retrieves the company's official LinkedIn, Twitter, and Facebook URLs.
* Fetches the company's location (City, Country) and a short description.
* Shows the estimated number of employees.
* Clean and error-handled console output.

## Prerequisites 🛠️
You need to have Python installed on your system. You also need an API key from [Apollo.io](https://www.apollo.io/).
